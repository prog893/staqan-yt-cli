# Engagement Commands

Commands for working with comments and captions on YouTube videos.

## list-comments

List comments for a YouTube video.

### Usage

```bash
staqan-yt list-comments --video-id <videoId>
```

### Options

- `--video-id <id>` - YouTube video ID or video URL (required)

- `--output <format>` - Output format: json, table, csv, text, pretty (default: pretty)
- `-l, --limit <number>` - Limit number of results (default: 20)
- `-s, --sort <order>` - Sort order: `top` or `new` (default: `top`)
- `-v, --verbose` - Enable verbose output with debug information
- `-h, --help` - Show help

### Examples

```bash
# List top comments
staqan-yt list-comments --video-id dQw4w9WgXcQ

# List newest comments first
staqan-yt list-comments --video-id dQw4w9WgXcQ --sort new

# Get more comments
staqan-yt list-comments --video-id dQw4w9WgXcQ --limit 50

# Export to CSV
staqan-yt list-comments --video-id dQw4w9WgXcQ --output csv > comments.csv

# Export to JSON
staqan-yt list-comments --video-id dQw4w9WgXcQ --output json
```

### Output Fields

- `id` - Comment ID
- `authorDisplayName` - Author name
- `textOriginal` - Comment text
- `likeCount` - Number of likes
- `publishedAt` - Publication date
- `updatedAt` - Last updated date
- `parentId` - Parent comment ID (for replies)

### Sort Orders

- `top` (default) - Sort by likes (most popular first)
- `new` - Sort by publication date (newest first)

### Use Cases

- **Engagement monitoring** - Track audience feedback
- **Sentiment analysis** - Analyze comment sentiment
- **FAQ extraction** - Find common questions
- **Community insights** - Understand audience needs

## list-captions

List all caption tracks for a YouTube video.

### Usage

```bash
staqan-yt list-captions --video-id <videoId>
```

### Options

- `--video-id <id>` - YouTube video ID or video URL (required)

- `--output <format>` - Output format: json, table, text, csv, pretty (default: pretty)
- `-v, --verbose` - Enable verbose output with debug information
- `-h, --help` - Show help

### Examples

```bash
# List all captions
staqan-yt list-captions --video-id dQw4w9WgXcQ

# Export to JSON
staqan-yt list-captions --video-id dQw4w9WgXcQ --output json

# Find YouTube-generated captions
staqan-yt list-captions --video-id dQw4w9WgXcQ --output json | \
  jq '.[] | select(.trackKind == "automatic")'

# Find tracks that exist but are not shown to viewers
staqan-yt list-captions --video-id dQw4w9WgXcQ --output json | \
  jq '.[] | select(.status != "serving" or .isDraft)'
```

### Output Fields

- `id` - Caption track ID (used for download)
- `language` - Language code (e.g., "en", "ja")
- `languageName` - Human-readable language name, falling back to the code for languages outside `en`/`ja`/`ru`
- `name` - Track label set by the uploader. Empty for auto-generated tracks
- `trackKind` - One of `manual` (user-uploaded) or `automatic` (YouTube-generated)
- `isAutoGenerated` - Same as `trackKind == "automatic"`
- `isAutoSynced` - Timing was machine-synced against the audio from an untimed transcript
- `isClosedCaptions` - Track is closed captions rather than plain subtitles
- `isLarge` - Track uses large text
- `isEasyReader` - Track is a simplified, third-grade-reading-level version
- `isDraft` - Track is a draft and is **not** shown to viewers
- `status` - One of `serving`, `syncing`, `failed`, or `unknown`
- `audioTrackType` - Which audio track the captions belong to: `primary`, `commentary`, `descriptive`, or `unknown`
- `failureReason` - Why processing failed. Only populated when `status` is `failed`, otherwise `null`
- `lastUpdated` - ISO 8601 timestamp of the last modification

### Is the Track Actually Live?

A caption track can exist and still show nothing on the video. Captions are
visible to viewers only when `status` is `serving` **and** `isDraft` is `false`.
A `syncing` track is still being timed against the audio, and a `failed` one was
rejected during processing (see `failureReason`). The `pretty` and `table`
formats report this as a `Visibility` / `status` field so a draft or failed
track is not mistaken for a working one.

> **`serving` does not mean visible.** A draft track is reported by the API as
> `status: "serving"` with `isDraft: true`. Filter on both fields, never on
> `status` alone:
>
> ```bash
> # Tracks actually shown to viewers
> staqan-yt list-captions --video-id VIDEO_ID --output json | \
>   jq '.[] | select(.status == "serving" and .isDraft == false)'
> ```

### Caption Sources

**Manual (`manual`):**
- Created by the video owner
- Higher accuracy
- May include timing for emphasis

**Automatic (`automatic`):**
- Generated by YouTube (speech recognition or other)
- Available for most videos
- Variable accuracy

## get-caption

Download caption content to stdout.

### Usage

```bash
staqan-yt get-caption --caption-id <captionId>
```

### Options

- `--caption-id <id>` - Caption track ID (get from `list-captions`) (required)

- `--format <format>` - Caption format: srt, vtt, sbv, scc, ttml, json (default: json)
- `-v, --verbose` - Enable verbose output with debug information
- `-h, --help` - Show help

> **Ownership requirement:** The YouTube API only allows downloading captions from videos on your own authenticated channel. `list-captions` works for any video, but `get-caption` will return a permissions error for videos you don't own.

### Examples

```bash
# List captions on one of your own videos to get the caption ID
staqan-yt list-captions --video-id <your-video-id>

# Download captions (JSON format by default)
staqan-yt get-caption --caption-id <caption-id>

# Download as SRT (subtitle file format)
staqan-yt get-caption --caption-id <caption-id> --format srt > captions.srt

# Download as VTT
staqan-yt get-caption --caption-id <caption-id> --format vtt > captions.vtt

# Download as text
staqan-yt get-caption --caption-id <caption-id> --format json | jq -r '.[].text'
```

### Caption Formats

**Text formats:**
- `json` - Structured JSON with timing (default)
- `scc` - Scenarist Closed Caption format

**Subtitle formats:**
- `srt` - SubRip format (most players)
- `vtt` - WebVTT format (web players)
- `sbv` - YouTube subtitle format
- `ttml` - TTML format (professional)

### Caption ID Format

Caption IDs typically follow the format:
```
<language_code>.<video_id>
```

Examples:
- `en.<video-id>` - English captions
- `ja.<video-id>` - Japanese captions
- `en.<video-id>.3` - Multiple English tracks

Use `staqan-yt list-captions --video-id <your-video-id>` to get the exact caption ID for your videos.

### Working with Captions

**Extract plain text:**

```bash
staqan-yt get-caption --caption-id <caption-id> --format json | \
  jq -r '.[].text' > transcript.txt
```

**Create word cloud:**

```bash
staqan-yt get-caption --caption-id <caption-id> --format json | \
  jq -r '.[].text' | \
  tr '[:upper:]' '[:lower:]' | \
  tr -d '[:punct:]' | \
  tr ' ' '\n' | \
  sort | uniq -c | sort -rn
```

**Find mentions:**

```bash
staqan-yt get-caption --caption-id <caption-id> --format json | \
  jq -r '.[].text' | \
  grep -i '@\|twitter\|instagram'
```

## put-caption

Upload a new caption track to a video on your channel.

### Usage

```bash
staqan-yt put-caption --video-id <videoId> --language <lang> --file <path>
```

### Options

- `--video-id <id>` - Video ID (must be on your authenticated channel) (required)
- `--language <lang>` - Caption language as a BCP-47 code, e.g. `ja`, `en`, `ko` (required)
- `--file <path>` - Caption file: `.srt`, `.sbv`, `.vtt`, `.ttml`, `.dfxp`, or `.scc` (required). Other file types (e.g. `.txt`) are rejected client-side — the API would accept them and then fail processing with `unknownFormat`, leaving a broken track
- `--name <name>` - Track name shown in the player (default: empty)
- `--draft` - Upload as a draft (not visible to viewers until published in YouTube Studio)
- `-f, --force` - If a track with the same language and name already exists, replace its content (via `captions.update`) instead of failing
- `--output <format>` - Output format: json, table, text, pretty, csv (default: pretty). Machine formats emit the created track (`id`, `videoId`, `language`, `name`, `isDraft`)
- `-v, --verbose` - Enable verbose output with debug information

### Examples

```bash
# Upload Japanese subtitles
staqan-yt put-caption --video-id dQw4w9WgXcQ --language ja --file ./subs/ja.srt

# Upload as a draft for review in Studio, get the caption ID for scripting
staqan-yt put-caption --video-id dQw4w9WgXcQ --language en --file en.vtt --draft --output json
```

> **PUT semantics:** like `put-video-localization`, this creates a new track and the API rejects the upload if a track with the same language and name already exists. Use `list-captions` to check what exists first, or pass `--force` to overwrite the existing track's content.

## Common Patterns

### Analyze Comment Sentiment

```bash
# Export comments for sentiment analysis
staqan-yt list-comments --video-id VIDEO_ID --output json | \
  jq -r '.[].textOriginal' > comments.txt

# Use with sentiment analysis tools
# sentiment_analysis comments.txt
```

### Find Most Liked Comments

```bash
# Sort comments by likes
staqan-yt list-comments --video-id VIDEO_ID --output json | \
  jq 'sort_by(.likeCount | tonumber) | reverse | .[0:10]'
```

### Extract Video Transcript

```bash
# Get plain text transcript from captions
staqan-yt list-captions --video-id VIDEO_ID --output json | \
  jq -r '.[0].id' | \
  xargs staqan-yt get-caption --caption-id --format json | \
  jq -r '.[].text' > transcript.txt
```

### Download Multiple Captions

```bash
# Download all available caption tracks
staqan-yt list-captions --video-id VIDEO_ID --output json | \
  jq -r '.[].id' | \
  while read caption_id; do
    language=$(echo $caption_id | cut -d. -f1)
    staqan-yt get-caption --caption-id "$caption_id" --format srt > "${language}.srt"
  done
```

### Caption Search

```bash
# Search for specific terms in captions
staqan-yt get-caption --caption-id en.VIDEO_ID --format json | \
  jq -r '.[] | select(.text | contains("keyword"))'
```

### Comment Frequency Analysis

```bash
# Find most common words in comments
staqan-yt list-comments --video-id VIDEO_ID --output json | \
  jq -r '.[].textOriginal' | \
  tr '[:upper:]' '[:lower:]' | \
  tr -d '[:punct:]' | \
  tr ' ' '\n' | \
  sort | uniq -c | sort -rn | head -n 20
```

## Tips

1. **Use `--limit`** to control number of comments retrieved
2. **Sort by `new`** for latest feedback, `top` for most popular
3. **Export to JSON** for text analysis and NLP
4. **Use SRT format** for subtitle editors
5. **Auto-generated captions** are available for most videos
6. **Manual captions** are more accurate but not always available

## Notes

- **Comments** - Public comments on videos (requires read scope)
- **Captions** - Subtitle tracks (including auto-generated)
- **Data delay** - Comments and captions update in real-time
- **Rate limits** - Respect YouTube API rate limits
